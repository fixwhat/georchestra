# How to upgrade georchestra

There are two types of upgrades:

* major version upgrades
* intermediate updates, module by module


## Major version upgrades

Each major upgrade is accompanied by migration notes. These are available at the address below and provide details on the most significant changes.

[https://github.com/georchestra/georchestra/tree/master/migrations](https://github.com/georchestra/georchestra/tree/master/migrations)


## Intermediate module updates

The 2025-2026 geOrchestra's codebase reorganization ([GIP #14](https://github.com/georchestra/improvement-proposals/issues/14)) let administrators an easier way to update a single module of geOrchestra.

Please report to each release available module by module on github. Example with GeoServer : [https://github.com/georchestra/geoserver/releases](https://github.com/georchestra/geoserver/releases)
